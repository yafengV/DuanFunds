# DuanFunds（基金估值 / 持仓）

一个使用 **Node.js + Express + 原生前端** 实现的移动端基金估值页面（类似“养基宝”的基础能力）。

## 功能

- 首页：
  - 顶部展示「总持仓」「当日盈亏」
  - 列表字段：名称、持仓金额、当日涨幅、当日收益、持仓涨幅、持仓收益
  - **名称列固定不滚动**，其余列支持左右滑动
- 添加流程：
  - 顶部“添加”进入【搜索基金】页，支持按 **代码/名称/拼音** 搜索
  - 点击结果进入【添加持仓】页，输入：持仓金额、持有收益
  - 添加成功后首页可见（支持同 code 覆盖更新、支持删除）

## 技术栈

- Node.js (建议 >= 18，当前项目在 Node 22 测试)
- Express
- 前端：HTML/CSS/JS（无框架，适配手机访问）
- 数据持久化：本地 JSON 文件（`data/holdings.json`）

## 接口来源（公开数据）

> 仅用于学习/自用；接口可能不稳定或随时变更。

- 基金列表（用于搜索）：
  - `https://fund.eastmoney.com/js/fundcode_search.js`
  - 服务端会缓存到 `data/funds_cache.json`（默认 7 天更新一次）
- 基金当日估值/涨幅：
  - `https://fundgz.1234567.com.cn/js/{基金代码}.js`
  - 该接口返回 JSONP，服务端做了解析并返回 JSON

## 启动

```bash
cd DuanFunds
npm i
npm run start
# 默认监听 0.0.0.0:3007
```

自定义端口/监听：

```bash
HOST=0.0.0.0 PORT=3010 npm run start
```

打开浏览器访问：

- `http://<本机IP>:3007`

## Docker 部署

```bash
cd DuanFunds
docker compose up -d --build
# 访问 http://<服务器IP>:3007
```

停止：

```bash
docker compose down
```

## 数据说明

- **持仓金额**：你当前投入/持有的金额（用于计算当日收益）
- **持有收益**：你截至目前的累计收益（可为负）。
  - 首页「持仓收益」直接展示该值
  - 「持仓涨幅」= 持有收益 / 持仓金额
- 「当日收益」= 持仓金额 × 当日涨幅

## 已知限制

- 估值接口与基金列表接口为第三方公开数据：
  - 可能出现跨域/限流/接口调整导致不可用
  - 本项目会在 UI 上显示“接口异常”提示，但不会保证实时可用性
- 未接入登录体系，数据仅保存在本机 `data/holdings.json`
